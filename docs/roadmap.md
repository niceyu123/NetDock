# 路线图

- M0/M1：现有原生多 Target、共享 Core、TCP Client/Server 与真实 loopback 测试。
- M2：已增加 UDP 单播、绑定、IPv4/IPv6、多来源回复与报文边界；真机双设备验收仍待补充。
- M3：已增加周期发送、快捷指令、搜索/过滤、统计、配置及日志导入导出；本轮自动化和截图结果见 testing-m2-m3-monitor.md。
- macOS 网络连接监控：用户授权的独立增量功能，保留沙盒与可见范围提示；见 connection-monitor.md。
- M4：真机局域网/权限/生命周期、吞吐与无障碍完整矩阵、最低系统运行、正式签名及发布准备。

仍不实现广播/组播、TLS、诊断/扫描工具、账号或云服务。TCP 自动重连留待后续单独实现与验收。
